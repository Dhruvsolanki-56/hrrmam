# Neo platform: strict UX audit (26 Oct 2026)

I walked through every page twice. First as a first-time user with no technical background: Neha (Artwork), Priya (Project Manager) and Vikram (Admin). Then as a UI/UX designer. I tested on a desktop screen and on a phone (375 px wide).

How to read the severity labels:

- **High**: confuses a first-time user or blocks a task.
- **Medium**: looks unprofessional or makes the user work harder than needed.
- **Low**: polish.

## Overall verdict

The core flow now works, and the pages explain themselves better than before: who has an item, why, and what happens next.

The site still does not feel *easy* for a non-technical person, for three reasons:

1. **It talks like the specification, not like a colleague.** Pages show jargon (COA, MSDS, CDA, POA, RA, Module 3, M1–M5, TGA, AUST R). Some spec notes appear on screen word for word, such as "(to be confirmed: account / secure upload / internal entry)". Instructions to the user are in the third person ("Neha Kulkarni (Artwork) must upload…", shown to Neha herself).
2. **The same fact is repeated in many places.** A returned document says it is "Returned", "Back with Neha", "To be corrected by Neha" and "Next action Neha must…" all on one card. The red blocker banner repeats on every tab.
3. **Pages show things the user cannot act on.** Neha gets the full executive overview, evidence-link inputs on other people's RFI questions, and an "Add document" button. Priya gets disabled Submit buttons and an empty "My artwork tasks" box.

## Every page

### Sign-in (choose a user)
- **High**: Role descriptions use jargon: "PV, CDA, POA", "RFIs", "COA, MSDS". A new starter does not know these.
- **Medium**: Cards are uneven heights. Avatar colours change from card to card for no reason. The arrows are tiny click targets.
- **Low**: The decorative progress bar on the left means nothing.

### Overview (dashboard)
- **High**: Every role sees the portfolio dashboard (Live projects 19, Unsigned agreements 23 and so on). For Neha or Suresh this is noise. Show the Start-here card and their own work; keep the portfolio view for Director, Manager and Admin.
- **Medium**: "Your next step" stays empty for about 1 s while it loads, so the first thing a new user sees is a blank dark box.
- **Low**: Typing `/board` in the address bar silently sends you to Overview, because the Board page lives at `/projects?view=board`.

### My work
- **High**: Text speaks *about* the user, not *to* the user. "Neha Kulkarni (Artwork) must upload the corrected version…" should say "Upload the corrected version and send it back."
- **Medium**: Rows are built differently. Document rows have an Open button; task rows do not.
- **Medium**: The "↺ 1" symbol is unexplained. The type "document" is in lowercase. Times like "3:34 am" add noise where a date is enough.
- **Medium (phone)**: The first chip is "Needs my decision 0", even when the user has nothing there. Empty groups should be hidden or moved to the end.

### Project page (redesigned header card)
- **High**: The numbers contradict each other. The header says "10 of 16 steps done"; the step card says "Step 6 of 11"; the Manufacturer tab says "Step 3 of 11".
- **Medium**: Grammar: "Anjali Desai (Regulatory) do the work and submit it." "Only Suresh Patel (…) submit this step." There are nested brackets: "Technical coordinator (Suresh Patel (Technical / Manufacturer data))".
- **Medium**: The Manager sees a disabled "Submit for approval" button that they cannot use. Hide it, or replace it with a sentence.
- **Medium**: "Project actions: Hold, move back, lock +" is cryptic.
- **Medium**: "History of this step (28)" sits next to a separate History tab, so there are two places for history.
- **Medium**: Target submission was 6 Sept 2026, which is in the past, but nothing flags it as overdue.
- **Low**: "now: RFI / Changes" is lowercase in the header.

### Project tabs
- **Brief**
  - **Medium**: The two-column field grid is unbalanced.
  - **Medium**: "Product" and "Product and formulation" show the same value twice.
- **Manufacturer**
  - **High**: The spec note "Access model: Internal entry by Neo technical team (to be confirmed …)" is shown on screen.
  - **Medium**: Jargon: COA, MSDS, Module 3, "RA reviewer".
  - **Medium**: The blocker list is shown to people who cannot act on it.
- **RFI**
  - **High**: Neha sees "Evidence link" inputs and Save buttons on questions assigned to other people.
  - **Medium**: The "Response package link" field has no explanation. "TGA" is not explained.
  - **Medium**: "RFI RFI-2026-115" repeats the word.
- **Tasks**
  - **Medium**: The status "Accepted" (the person agreed to do it) is easily read as "approved". "Submitted" next to it adds to the confusion. Better wording: "In progress" and "Waiting for approval".
- **Documents**
  - **High**: Neha (Artwork) can see "Add document" on regulatory documents. Either the permission is too loose, or the button should not show.
- **Critical blocker banner**
  - **Medium**: A large red block repeats on every tab. Show it once on Overview and use a small marker elsewhere.

### Returned-document card
- **High**: The same fact appears 3–4 times (see the overall verdict).
- **Medium**: There are two ways to write a note: a message box *and* "+ Add a note". Keep one.
- **Low**: "open" links are lowercase.

### All projects / Completed
- **Medium**: On the Completed page, the Health column says "Closed" and Target submission shows an old plan date. Show the completion date instead.
- **Low**: Completed is just a filter of All projects but takes its own place in the sidebar.

### Board
- **Medium**: The column name "Parallel workstreams" and the card text "Legal / Agreements · +4 parallel" are internal language. Try "Preparation (5 teams working)".
- **Medium**: Cards in the Closed column show "Closed" *and* "Completed".
- **Low**: "no code yet" in grey reads like an error.

### New project dialog
- **High**: Jargon: "(decides which M1–M5 modules the dossier needs)", "AUST R / AUST L". The sentence "One project record is shared by Neo Health Australia and Neo India" is meaningless to a newcomer.
- **Medium**: Required fields are not marked. "Initiator" is free text with no explanation.
- **Medium**: The dialog scrolls inside itself, so Target dates and Summary are hidden below the fold.

### Regulatory workstream
- **Medium**: The page is blank while loading, with no skeleton, and took about 2 s on first open.
- **Medium**: "RA review queue" is jargon. Item statuses ("Received", "Under review", "Under review on stage awaiting approval") use a different vocabulary from the rest of the site.
- **Medium**: The left column "My regulatory tasks" shows the Manager's own tasks and leaves a large empty area.

### Artwork workstream
- **Medium**: Titles and sub-lines are cut off with "…" (for example "Consumer medicine leaflet – Ibuprofen 5% g…"). "V1" is not explained.
- **Medium**: A Project Manager sees "My artwork tasks: No open artwork tasks". This box is irrelevant to that role.
- **Medium**: The page is blank while loading.

### Legal register
- **Medium**: The Type column wraps to 3 lines, and the table scrolls sideways on narrow laptops.
- **Low**: The "SR" column header is an unexplained abbreviation.

### Audit trail
- **Medium**: The filter tabs overflow and get clipped (an "I" is cut off on the right). "Stage" is used here, but "step" is used everywhere else.
- **Low**: Project names wrap onto 2 lines.

### Notifications
- **High**: The badge says 12 unread, but the panel lists 60 items with no "Mark all as read".
- **Medium**: Repeated reminder entries have identical timestamps. The panel loads only after it is opened, so it feels slow.

### Admin (Vikram)
- **High**: Changing a role in the Users table takes effect immediately, with no confirmation. One mis-click changes someone's access.
- **High**: The Settings page shows spec text: "TGA external submission platform (to be confirmed)", "comma-separated, 0 = due today, default 7,3,1,0".
- **Medium**: In Roles & permissions, the column headers are in capitals and wrap to 6 lines ("CLIENT REVIEWER (VIEW AND COMMENT ON THE PROCESS)"). Permission names like "BYPASS OPTIONAL" are code names.
- **Medium**: Every sub-tab is blank while loading. A greyed-out "Administrator / admin@example.com" row looks broken.

### Help ("How this works")
- **Good**: It is clear, short and plain-language. This is the best page on the site.
- **Low**: It is long on a phone and has no jump links. The glossary should also cover the jargon used elsewhere: COA, MSDS, PV, CDA, POA, TGA, RA.

### Phone
- **Good**: The project header card, My work and the menu all fit without sideways scrolling.
- **Medium**: The project tabs scroll sideways with no visible hint beyond a fade. The summary is cut to one line.

## Top 10 fixes, in order

1. Speak to the user: "Upload the corrected version", not "Neha Kulkarni (Artwork) must…".
2. Remove all spec and "(to be confirmed)" text from the Manufacturer tab and Admin Settings.
3. Replace or explain the jargon everywhere, and add the missing terms to the Help glossary.
4. Give each role its own Overview; keep the portfolio dashboard for Director, Manager and Admin.
5. Hide controls the user cannot use: RFI evidence inputs, "Add document", disabled Submit buttons, empty "My … tasks" boxes.
6. Say each fact once on cards: one status line and one "what you do next" line.
7. Make the step numbers agree (16 vs 11).
8. Notifications: make the count match what is listed, and add "Mark all as read".
9. Ask for confirmation before changing a role in Admin.
10. Show loading skeletons on the workstream and Admin pages, and fix clipped text (artwork titles, audit filters, Legal Type column).
